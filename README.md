# Farhaan Qaisar Usmani — Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Run locally

From this directory, run `python3 -m http.server 8000` and open http://localhost:8000.

## Files

- `index.html` — portfolio sections and project showcases
- `style.css` — responsive styling and reduced-motion support
- `app.js` — network animation, scroll reveals, project dialogs, and email copying
- `resume.pdf` — downloadable resume

No build step is required. Serve the repository root with any static host. Google Fonts is used for typography, with local font fallbacks.
